01

收錄範圍

依公開貼文文字、作者提供的連結與官方 repo 查核。這不是完整歷史清單。

02

原文不一定等於現況

介紹以官方 README 為準。名稱與連結不符、repo 搬家、已封存、非商用或混合授權，都在條目內說明。無法確認的內容保留為待核，不猜網址。

星數變動快，也不是品質保證，因此不沿用貼文的歷史星數作排名。

03

使用前再看一次

沒有安裝或執行這些專案；入門說明僅供選擇工具。實際使用前請閱讀最新版文件、授權、權限與費用。API、模型、硬體與託管可能另需付費。

金融工具不構成投資建議；資安與自動化工具只用於取得授權的環境。
