## 本機預覽與測試

用任意靜態 HTTP server 開啟根目錄，例如 `python -m http.server 8000`。測試：`node --test tests.mjs`。

GitHub Pages 使用 `main` 分支根目錄。`.nojekyll` 停用 Jekyll。
